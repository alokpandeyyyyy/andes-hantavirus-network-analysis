# Robustness Analysis of an Andes Hantavirus Transmission Network

## Overview

This project was completed as part of my internship at Motilal Nehru National Institute of Technology Allahabad (MNNIT Allahabad).

The project focuses on modeling and analyzing an Andes Hantavirus transmission network using Python and NetworkX, with emphasis on network robustness.

## Technologies Used

- Python
- Pandas
- NetworkX
- Graph Theory
- Jupyter Notebook

## Key Areas

- Transmission Network Modeling
- Directed Graph Analysis
- Network Metrics
- Shortest Path Analysis
- Centrality Analysis
- Robustness Analysis
